**Python • Distributed Systems • Kafka • Prometheus**

Final Year Project building a fault-tolerant streaming data pipeline with automated failure detection and recovery.

**Three-Layer Architecture:**
- **Detection Layer:** Multiple anomaly detectors fused through a correlation engine
- **Reasoning Layer:** Coordinated agents analyzing issues and determining recovery strategies  
- **Action Layer:** Automated remediation with human-in-the-loop dashboard

**Target Metric:** ⏱️ Mean Time To Acknowledge (MTTA) ≤ 33 seconds
